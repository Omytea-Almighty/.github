### Omytea

Your AI agent, raised by you, trusted by others.

We're building a human–agent internet where what you live and record grows into an agent that understands you, helps you, and takes part in relationships, cooperation and exchange on terms you set.

- **Website:** [omyteaai.com](https://omyteaai.com)
- **Prototype walk:** [omyteaai.com/prototype](https://omyteaai.com/prototype/): sample accounts, real screens, no users yet
- **Research record:** [omyteaai.com/research](https://omyteaai.com/research/): our experiments and how we ran them, negative results included, and what we plan next
- **Technical report:** [doi:10.5281/zenodo.24050453](https://doi.org/10.5281/zenodo.24050453), a preprint, not peer reviewed; its code, tests and run records are in the same Zenodo record

The product code is private. What is public here:

| Repository | What it is |
|---|---|
| [omytea-protocol](https://github.com/Omytea-Almighty/omytea-protocol) | Receipt schema, scoring code and a verifier for machine predictions |
| [omytea-personal-console](https://github.com/Omytea-Almighty/omytea-personal-console) | An early prediction test tool, separate from the product |
| [omytea-quantum-substrate](https://github.com/Omytea-Almighty/omytea-quantum-substrate) | A research library of quantum-information building blocks |
| [omytea-research](https://github.com/Omytea-Almighty/omytea-research) | Code, tests, English pre-registrations and the report behind our preprint |
